How it works: every active skill slot gets one option from that Survivor’s own list. A slot reroll changes only that slot. The generator does not try to prevent duplicate skill names across different slots; each slot is randomized independently from its own valid options.

Character database & editing

The data below is the source of truth. You can correct names or add missing alternate skills in the editor, then press “Apply data”. Save a copy of this HTML file to keep your changes. Data uses JSON: each survivor has a name, DLC, and slots; each slot has a name and an options array.
